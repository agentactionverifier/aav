# Security policy — first alpha

## Reporting vulnerabilities

Report vulnerabilities privately to **security@agentactionverifier.com**, the owner-approved security contact. Do not open a public issue containing exploit details or credentials. Acknowledgement and coordinated-disclosure timelines remain subject to the final human release approval; no response SLA is promised.

Reports should identify the package/version, impact, prerequisites, and minimal reproduction. Remove real tokens, personal data, production URLs and destructive payloads.

In scope: policy/approval bypass, credential disclosure, audit integrity, unsafe execution, configuration traversal, and local authentication. The inability to enforce an action routed outside AAV is a documented limitation; see the [security model](docs/local/mcp-security-model.md).

No public supported version exists yet; a maintenance policy is required before release.
